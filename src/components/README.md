# Component Guide

This folder is grouped by page section so the portfolio is easy to edit.

- `FounderHero.jsx`: top founder intro, bio, CTA, social links, and brand card placement.
- `FounderBrandCard.jsx`: right-side brand panel with initials, highlights, and location.
- `FounderSnapshot.jsx`: quick contact cards under the hero.
- `LinkSection.jsx`: renders each data-driven resource/contact/social section.
- `LinkCard.jsx`: single card used inside every `LinkSection`.
- `SocialBar.jsx`: icon-only social/contact buttons in the hero.

Most text, links, phone numbers, and card content live in `../data/linksData.js`. Edit that file first when changing portfolio content.
